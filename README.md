# FACTUM: A Mechanistic Framework for Citation Hallucination Detection

This repository contains the official code and data for the FACTUM framework used for citation hallucination detection. This framework consists of four mechanistic scores designed to use a model's internal states to reliably detect citation hallucinations in long-form Retrieval-Augmented Generation (RAG) models.

## Repository Structure

This repository is organized into one main directory. Below is a high-level overview of its contents and purpose:

*   `FACTUM-main/`: **(Primary Folder)** This is the core of the repository. It contains the full implementation of the FACTUM framework, including the code for calculating all of the four scores (CAS, BOS, V_ffn, POS). It also houses the final, processed datasets that were used for the analysis and the results.

## Getting Started

To dive into the implementation of our method and the specifics of our experiments, please proceed to the `FACTUM-main` directory. More detailed documentation and instructions can be found within that folder's own `README.md` file.

```bash

```
